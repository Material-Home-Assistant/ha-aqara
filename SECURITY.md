# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you believe you have found a security vulnerability in the Aqara Camera G100 integration, please report it responsibly rather than opening a public issue.

### Reporting

Please send details to [giovannilamarmora.working@gmail.com](mailto:giovannilamarmora.working@gmail.com).

### Response

We will respond to your report within 5 business days and acknowledge your contribution in the release notes once fixed.
